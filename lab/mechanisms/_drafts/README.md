# Draft mechanism stubs

Files here are **auto-generated by `lab/watcher.py`** when a new subtensor release
is detected. They are **NOT imported** by `lab/mechanisms/__init__.py`, so nothing
here is registered, trusted, or run.

To promote a draft into a live mechanism:

1. Read the PR/source diff and confirm the exact `emission_share` formula
   (Action 1 / §4.0 — *read the code, not the blog*).
2. Implement `score(sub, state)` in the stub.
3. Move the file up to `lab/mechanisms/` and add a `register(Mechanism(...))` call.
4. Re-run the reproduction gate (`python -m lab.runner --live`) and confirm it
   still passes before trusting any projection.
